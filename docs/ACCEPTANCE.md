# 面向参考绘画的验收方案

目标是固定角色或画风、由用户线稿控制并持续获得有用参考。线条或服装细节不是必须逐像素一致，但丢失人物、姿态失控和角色特征消失属于核心问题。

## 先做一个真实预设

先由用户指定角色或画风及兼容 LoRA，填写 `profiles` 中的预设。不得将本地零增量 LoRA 接口测试当作角色一致性验证。

固定基础模型、LoRA、触发词、权重和种子；同一组输入依次保存起稿、补充姿势、修改表情、小幅修正四个阶段，并补充全身、双人等构图。三张已有用户原图只读，路径保留在历史交接文档，不重复索要。

用 `python -m tools.evaluate_quality --offline --profile profiles/实际预设.json --input 阶段1.png --input 阶段2.png` 生成预览/精细对照；可重复传入种子，但先完成一个固定种子的基线。脚本记录实际预设、最终提示词、步数、控制参数和运行时间；`manual_review` 字段留空供人工评审，不自动宣称画质通过。

| 维度 | 人工观察 |
|---|---|
| 角色或画风一致性 | 五官、发型、标志性特征或笔触/配色特征是否保留 |
| 线稿控制 | 人数、姿势、构图、表情是否随输入变化 |
| 连续稳定性 | 少量改笔是否让无关区域大幅跳变；精细档是否改变参考方案 |
| 参考价值 | 结构、光影或配色是否能帮助下一笔绘画，而非只判断精美程度 |
| 反馈速度 | 不停笔期间是否持续显示结果、最大显示间隔及快照到显示的 P95 |

静态顺序快照用于人工比较稳定性，不是实时输入性能测试。实时调度使用 `tools.continuous_preview`；真实窗口另用手动连续绘画验收，记录实际设备和是否预热。当前 5 秒预览年龄上限是可调产品阈值；低性能设备可能需要降低步数或放宽上限。

## 当前边界

- 真实角色/画风尚未指定，因此一致性验收未完成。
- 固定参考和默认手动精细重绘避免自动替换正在使用的参考，没有从算法上解决跨帧漂移。
- PNG 包含请求对应的线稿和参数，但尚非完整项目文件；不保存全部历史、编辑图层或模型文件。
- 此轮未重新训练模型，未宣称解决过去评估里的巨大脸部、构图失控等画质问题。
