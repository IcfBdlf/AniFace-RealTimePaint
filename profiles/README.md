# 角色与画风预设

复制 `example.json` 并填写本地 LoRA 路径和触发词。它是配置模板，不是已验证角色；未修改时会因缺少模型而明确报错，不会偷偷下载。

- `kind` 为 `character` 或 `style`。
- `base_model` 必须等于当前 `config.BASE_MODEL_ID`；当前不会动态切换基础模型。
- `lora_path` 可以是绝对路径，也可以相对该 JSON 的路径；支持当前 Diffusers 能加载的本地文件或目录。
- `weight` 范围 0–1.5；相同文件调整权重后重新加载只更新权重。
- `trigger_words` 固定在提示词前面，自由构图、动作和表情通过界面提示词编辑。
- `default_prompt` 为载入时的自由提示词；全身/双人请写对应构图，不要沿用单人头像描述。
- `control_end` 在 (0, 1] 范围；界面“尽量跟随线稿”打开时覆盖为 1.0。

预设加载成功后才替换当前角色/画风；失败时保留旧预设。预设只是固定生成配置，不是身份一致性保证。随机种子目前统一为 `config.SEED`，默认 42；模型/LoRA 文件内容及版本未完全锁定，仅凭参数和路径不能保证跨机器像素复现。

真实验收须选定一个角色或画风，使用兼容且质量可靠的 LoRA，按 [验收方案](../docs/ACCEPTANCE.md) 实测。此轮尚无用户指定的目标 LoRA。

当前底模为 `cagliostrolab/animagine-xl-3.1`，必须使用与其兼容的 SDXL LoRA；旧 SD1.5 LoRA 不能沿用。示例只提供格式，不包含角色权重。
